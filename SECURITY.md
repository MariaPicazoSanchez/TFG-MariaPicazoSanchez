# Security Policy

## Scope

This policy applies to the Movilidad ESII application and its build pipeline. The application runs entirely locally — it does not expose any network service beyond `127.0.0.1` and does not transmit data to external servers.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report them privately by emailing the author directly. You can find the contact details on the [author's GitHub profile](https://github.com/MariaPicazoSanchez).

Include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce it.
- Any proof-of-concept code or screenshots, if applicable.

You will receive an acknowledgement within 72 hours. Confirmed vulnerabilities will be fixed and disclosed responsibly.

## Supported versions

Only the latest release receives security fixes. Older versions are not maintained.

| Version | Supported |
|:---|:---:|
| Latest (`main`) | ✔ |
| Older releases | ✗ |
